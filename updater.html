Choose a Blockvile website zip or unzipped folder (for example the one you were sent) to install it on this device. It works offline and replaces what Blockvile shows until you remove it.

This is a separate app for updating Blockvile Plus OS. Updates never install by themselves, and your apps, files and settings stay as they are.
